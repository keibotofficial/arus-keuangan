Cara menghubungkan Google Sheets
  1. Buka database Google Sheets → Ekstensi → Apps Script.
  2. Tempel file backend Code.gs dan jalankan setup.
  3. Deploy sebagai Web App: jalankan sebagai pemilik, akses Anyone. Aplikasi tetap memerlukan kunci akses.
  4. Salin URL berakhiran /exec dan kunci akses ke formulir di atas.

Data asli disimpan di Google Sheets. Kunci dan sesi tidak disertakan dalam kode publik. Mode contoh hanya menggunakan penyimpanan browser.
